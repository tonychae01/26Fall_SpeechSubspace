# speech-subspace-alignment
Analyzing Population Subspace Structure in Pretrained Speech Models and Alignment with Auditory Cortex Circuits

**Beyond Single-Unit STRFs: Understanding Auditory Tuning Subspaces in HuBERT and wav2vec 2.0**
Tony Chae, Stefan Hajduk

## 폴더 구성

```text
00_reference/       프로젝트 계획, 진행 기록, requirements.txt
01_raw_data/        원본 데이터
02_processed_data/  전처리 데이터
03_src/             실험 및 분석 코드
04_checkpoints/     모델 및 학습 체크포인트
05_results/         실험 결과 요약과 그림
06_external/        외부 코드 및 자료
```

- [프로젝트 계획](00_reference/project_plan.md): 현재 합의한 초안. 추후 수정 가능.
- [진행 기록](00_reference/progress.md): 완료 여부, 현재 단계, 다음 작업.
- [결과 기록](05_results/README.md): 실제 수행한 실험의 결과를 간단히 기록.

현재는 폴더와 문서만 준비한 상태이며, 환경 설정·데이터 다운로드·실험은 아직 진행하지 않았습니다.
가상환경은 추후 저장소 바깥의 `envs` 폴더에 별도로 구성합니다.
